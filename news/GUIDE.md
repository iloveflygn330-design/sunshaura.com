# ニュース記事 作成ガイド

毎朝のスケジュールタスク（Claude）は、このファイルの手順どおりに記事を作成・公開する。
ルールを変えたいときは、タスク側ではなくこのファイルを書き換える（次回の実行から反映される）。

---

## 1. 作成する記事

- 1日1本。その日のニュースを **3〜5件** まとめた記事にする
- 対象は「前日の朝7時〜当日の朝7時（日本時間）」ごろに公開・発表された情報
- 記事の日付は **作成した当日（日本時間）**
- **当日の記事（news/column/YYYYMM/DD/）がすでにある場合は、何もせずに終了する**（手動で先に作った日や、再実行したときの二重作成を防ぐため）
- 過去の記事（直近7日分の article.json）と同じニュースは取り上げない
- 文章は日本語。英語の情報源は日本語で要約する

### 取り上げる優先順位

1. VRChat本体のアップデート・不具合・告知
2. VRChat関連のイベント（Vket など）、アバター・ワールド制作の話題
3. VR機器・ソーシャルVR全般の話題
4. 上記で3件に満たない日は、**AI関連のニュース** で補う
5. それでも1件も見つからない日は、記事を作らずに終了する（「特になし」の記事は作らない）

### 禁止事項

- 記事本文・画像の転載（引用する場合も1か所15語未満まで。基本は自分の言葉で要約する）
- 他サイトの画像をサムネイルに使うこと
- 出典のない情報、未確認の噂を事実として書くこと
- 特定の個人を批判・晒す内容

## 3. 記事の書き方

- **タイトル**: その日の一番大きな話題を中心に、40文字程度（例：「VRChatに新アバター機能が登場ほか、今日のVRニュース4本」）
- **intro**: 今日の記事全体の紹介を2〜3文
- **各ニュース**
  - headline: そのニュースの見出し（30文字程度）
  - overview: 何が起きたかの概要を3〜4文、自分の言葉で
  - points: 読者にとってのポイントを2〜4個、箇条書き（1つ40文字程度）
  - sources: 出典の名前とURL（必ず1つ以上）
- **outro**: 締めの一言（任意。1〜2文）
- 文体は「です・ます」。主観的な感想は控えめにし、事実とポイントを中心にする

## 5. サムネイル

自分で用意した画像を、カテゴリごとのフォルダから選んで使う。**他サイトの画像は使わない。**

1. その日の **1件目のニュースのカテゴリ** に対応するフォルダを見る（下の表）
2. フォルダ内の画像（.jpg / .jpeg / .png / .webp）のうち、**news/data/articles.json の直近の記事で使っていないもの** を選ぶ
   - 未使用の画像が複数あれば、どれを選んでもよい
   - すべて使用済みなら、いちばん前に使われたもの（articles.json で最も古い使用）を選ぶ
3. article.json と articles.json の thumb に、news/ からの相対パスを書く（例: `"assets/thumbs/world/world-sunset-01.jpg"`）
4. フォルダに画像が1枚もないときは、thumb は空文字 `""` にする（カテゴリ色とアイコンの自動サムネイルになる）
5. 画像ファイルはコピー・移動・編集しない（パスを書くだけ）

| カテゴリ | フォルダ |

| イベント | news/assets/thumbs/event/ |
| アバター・制作 | news/assets/thumbs/avatar/ |
| ワールド | news/assets/thumbs/world/ |
| VR機器・技術 | news/assets/thumbs/device/ |
| AI | news/assets/thumbs/ai/ |
| その他 | news/assets/thumbs/other/ |

## 6. ファイルの置き方

日付が 2026-10-10 の場合:

```
news/column/202610/10/index.html   ← news/column/_template/index.html をそのままコピー
news/column/202610/10/article.json ← 記事の中身（下の形式）
news/column/202610/10/script.json  ← 動画の読み上げ台本（「8. 動画の台本」の形式）
news/data/articles.json            ← 先頭に一覧用の1件を追加
```

### 記事データの形式（article.json）

```json
{
  "date": "2026-10-10",
  "title": "記事タイトル",
  "category": "VRChat公式",
  "thumb": "",
  "intro": "今日の記事全体の紹介。",
  "items": [
    {
      "headline": "ニュースの見出し",
      "category": "VRChat公式",
      "overview": "概要の文章。",
      "points": ["ポイント1", "ポイント2"],
      "sources": [{ "name": "VRChat公式ブログ", "url": "https://..." }]
    }
  ],
  "outro": "締めの一言。"
}
```

- thumb は「5. サムネイル」の手順で選んだ画像のパス。画像がないカテゴリは空文字 ""（カテゴリ色とアイコンでサムネイルが自動表示される）

### 一覧データの形式（articles.json に追加する1件）

```json
{ "date": "2026-10-10", "title": "記事タイトル", "category": "VRChat公式", "thumb": "" }
```

- 配列の **先頭** に追加する（新しい記事が上）
- date / title / category / thumb は article.json と同じ値にする

## 7. 公開

1. JSONが正しい形式か確認する（article.json / script.json / articles.json が `python3 -m json.tool` 等で読み込めること）
2. コミットメッセージ: `news: 2026-10-10 記事タイトル`
3. main ブランチに push する
4. push されると GitHub Actions（.github/workflows/news-discord.yml）が
   Discord に記事のURLと見出しを自動で送る（タスク側で Discord に送る必要はない）
5. 同じく push をきっかけに GitHub Actions（.github/workflows/news-voice.yml）が
   script.json から読み上げ音声（voice.mp3）と video.json を作り、記事ページに動画が表示される
   （タスク側で音声を作る必要はない。voice.mp3 と video.json は作らないこと）

### キャラクターの設定（公式サイト https://zunko.jp/ に書かれていることだけ）

| キャラクター | 公式の設定 |
|---|---|
| ずんだもん | ずんだ餅がモチーフ。東北ずん子の必殺技「ずんだアロー」の弓に変身する。語尾は「〜のだ」「〜なのだ」、一人称は「ボク」。趣味は、その辺をふらふらすること、自分を大きく見せること |

| 東北きりたん | 11歳の小学5年生。東北3姉妹の末っ子。趣味はずん子、ゲーム、ひきこもること、同人誌漁り |
| 東北イタコ | 19歳。職業はイタコ（イタコ専門学校を首席で卒業）。東北3姉妹の長女。趣味はずん子のプロデュース |
| 四国めたん | 17歳。ずん子と同じクラス。趣味は中二病妄想 |
| あんこもん | 趣味は「ずんだもんに勝つこと（ただし実際は負けることが多い）」 |

**設定の使い方（重要）**

- 上の設定は、**会話の温度感や距離感をつくるための材料**として使う。セリフに説明として書き込むものではない
  - 例：ずん子とずんだもんは気心の知れた相棒の距離感、きりたんはゲームやVRの話題に食いつきがよい、あんこもんはずんだもんに張り合うが空回りしがち、イタコは落ち着いた年長者の雰囲気、など
- 「姉妹」「同級生」「ライバル」「ずんだアロー」「弓」などの言葉を、話の流れと関係なくセリフに入れない。自己紹介や設定説明のセリフも書かない
- 公式に書かれていない関係や口調（ファンの二次創作で定番の呼び方・口ぐせ・語尾など）は使わない。ずんだもん以外は、キャラクターらしい自然な話し言葉にとどめ、独自の語尾や口ぐせを作らない
- キャラクターをけなす・からかう内容は書かない（ずんだもんとあんこもんの張り合いも、仲の悪さではなく軽いやり取りにとどめる）

### 全体の構成と長さ

- 目標の長さは **2〜4分**（セリフ1行がおよそ3〜4秒）
- 順番は必ず「opening → news（記事の items の順に全件）→ fortune → ending」

| type | 内容 | セリフの目安 |
|---|---|---|
| opening | ずんだもんのあいさつ、ゲストの一言、今日の本数 | 3〜4行 |
| news | ニュース1件（item に記事の items の番号 0, 1, 2…） | 6〜9行。ずんだもんが概要とポイントを紹介し、ゲストが反応・質問する。最後はどちらかの一言感想 |
| fortune | 星座占い（12星座すべての順位を ranking に入れる） | 5〜6行。イタコが1〜3位と12位を発表し、ずんだもんが反応する。ゲストは話さない |
| ending | 締めのあいさつ（ずんだもんとゲスト） | 2〜3行 |

- 掛け合いの割合の目安：ずんだもん 6〜7割、ゲスト 3〜4割（ゲストばかり話さない）
- ニュースの事実関係はずんだもんが話す。ゲストは事実を付け足すより、反応・疑問・感想を担当する

### セリフの書き方

- `who` は話すキャラクター（`zundamon` / 今日のゲスト / 占いでは `itako`）
- 1行は **40文字以内**（字幕に出るため）
- 記事の文章をそのまま読まない。自分の言葉で、耳で聞いて分かる短い文にする
- `text` は字幕に表示する文。漢字・英語の表記のままでよい
- `read` は読み上げ用の文。**英単語・略語・数字・記号がある行は必ず書く**（VOICEVOXが誤読するため）。すべてカタカナかひらがなで書く
  - 例: text「Steamで20%値下げなのだ」→ read「スチームで、にじゅっパーセント値下げなのだ」
  - 例: VRChat → ブイアールチャット、Meta → メタ、9.99ドル → きゅうてんきゅうきゅうドル
  - 読み間違えようのない行は read を省略してよい
- `face` は表情。セリフの内容に合わせて選ぶ（同じ表情ばかりにならないように）
  - `normal`（ふつう・省略時）/ `smile`（笑顔：うれしい話題、あいさつ）/ `surprise`（驚き・困り：意外な話、不具合）
  - `amazement`（あきれ顔：ツッコミ、残念な話）/ `look`（横目：ちょっと気になる話、意味深な一言）
  - `nihilistic`（冷めた顔・悟った顔：きりたん専用。あきれ・脱力の場面）
  - キャラクターによっては無い表情がある（例：イタコに amazement は無い）。その場合は自動で近い表情になるので、気にせず指定してよい
- `style` は声色（省略時はノーマル）。**ここぞという場面でだけ**使い、1本の動画で数回まで
  - ずんだもん：`なみだめ`（悲しい・困った話）/ `ヘロヘロ`（脱力・12位の占いなど）/ `ささやき`・`ヒソヒソ`（内緒話ふうの一言）/ `ツンツン`（ちょっと拗ねる）/ `あまあま`（うれしくて甘える）
  - 四国めたん：`ツンツン` / `あまあま` / `ささやき` / `ヒソヒソ`
  - あんこもん：`つよつよ`（張り合って強気）/ `よわよわ`（負けを認める）/ `けだるげ` / `ささやき`
  - 東北ずん子・東北きりたん・東北イタコ：ノーマルのみ（style は書かない）

### 星座占い

- 12星座すべてに 1〜12位 をつけ、それぞれ一言（15文字程度）とラッキーアイテムを書く
- 毎日違う順位にする（前日の script.json と同じ順位にしない）
- 内容は前向きなものにする。12位でも、ひどいこと・不安をあおることは書かない
- 他の占いサイトの内容は使わない（エンタメとしての占い）

```json

  "speed": 1.15,
  "guest": "zunko",

    ]},
    { "type": "news", "item": 0, "lines": [
      { "who": "zundamon", "text": "1本目。…なのだ。", "read": "いっぽんめ。…なのだ。" },
      { "who": "zunko", "text": "それって、…ということですか？", "face": "surprise" }
    ]},
    { "type": "fortune",
      "ranking": [
        { "rank": 1, "sign": "てんびん座", "comment": "新しい道具との出会いが吉", "lucky": "ワイヤレスイヤホン" }
      ],
      "lines": [
        { "who": "zundamon", "text": "最後は星座占いなのだ！イタコさん、お願いするのだ。", "face": "smile" },
        { "who": "itako", "text": "今日の1位は、てんびん座です。", "read": "今日のいちいは、てんびんざです。" }
      ]
    },
    { "type": "ending", "lines": [
      { "who": "zunko", "text": "今日もありがとうございました。" },

    ]}
  ]
}
```

- 上の例のセリフはあくまで形式の例。毎日同じ言い回しにしない
