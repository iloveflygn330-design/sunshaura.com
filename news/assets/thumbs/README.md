# ニュース記事のサムネイル画像

毎日のニュース記事タスクは、その日の1件目のニュースのカテゴリに対応するフォルダから、サムネイル画像を1枚選んで使います。
フォルダが空のときは、カテゴリ色とアイコンの自動サムネイルが表示されます。

## フォルダとカテゴリの対応

| フォルダ | カテゴリ |
|---|---|
| vrchat/ | VRChat公式 |
| event/  | イベント |
| avatar/ | アバター・制作 |
| world/  | ワールド |
| device/ | VR機器・技術 |
| ai/     | AI |
| other/  | その他 |
