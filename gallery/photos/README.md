# フォトギャラリーの写真置き場（元の写真はPCにだけ置く）

このフォルダの写真は **GitHub には上がりません**（.gitignore で除外しています）。
元の写真は容量が大きいため、ここから圧縮版を作り、圧縮版（`gallery/generated/`）と
一覧（`gallery/data/photos.json`）だけを GitHub に上げます。

## 入れられるファイル

- 形式：`.jpg` `.jpeg` `.png` `.webp` `.gif` `.avif`
  - iPhoneの `.heic` は変換できないので、jpg か webp にしてから入れてください
- ファイル名は何でもOKです（サイト上には表示されません）

## 圧縮版の大きさ

- 並べる用：横 960px の WebP（1枚 40KB 前後）
- 拡大表示用：長辺 1920px の WebP（1枚 130KB 前後）
- 一覧では写真を **3:2** の枠に切り取って表示し、クリックした拡大表示では元の比率のまま全体を表示します

## 注意

- 元の写真はこのPCにしかありません。PCの故障に備えて、別の場所にもバックアップしておくと安心です。
- 圧縮版はサイトで公開されるため、誰でも見られます。他の人が写っている写真は、本人の許可を取ってから入れてください。
