# フォトギャラリーの写真置き場

このフォルダに入れた画像が、フォトギャラリー（`gallery/`）にランダムで3枚ずつ表示されます。

## フォルダの構成

```
gallery/photos/
  ├─ event/        ← アルバム「イベント」
  ├─ world/        ← アルバム「ワールド」
  ├─ （好きな名前のフォルダ）/  ← フォルダ名のアルバムになる
  └─ xxx.png       ← 直下の写真はアルバム「その他」
```

## 入れられるファイル

- 形式：`.jpg` `.jpeg` `.png` `.webp` `.gif` `.avif`
  - それ以外（このREADMEや `.heic` など）は自動で無視されます
  - iPhoneの `.heic` はブラウザで表示できないことが多いので、jpg か webp に変換してから入れてください
- ファイル名は何でもOKです（サイト上には表示されません）

## 画像サイズ

VRChatのスクリーンショットをそのまま入れて大丈夫です。
表示用の軽い WebP は GitHub Actions が自動で作ります（`gallery/generated/`）。

- 一覧では写真を **3:2** の枠に切り取って表示し、クリックした拡大表示では元の比率のまま全体を表示します
- push してから GitHub Actions が終わるまでの数分間は、新しく入れた写真はまだ並びません
  （一覧がまだ1枚もない最初の1回だけは、Actions を待たずに元の画像で表示されます）

## 注意

- このリポジトリは公開されているため、ここに入れた写真は誰でも見られます。
  他の人が写っている写真は、本人の許可を取ってから入れてください。
- GitHub のリポジトリには容量の目安（1GB程度）があります。元の写真が大量に増えてきたら、
  先に縮小してから入れることも検討してください。
