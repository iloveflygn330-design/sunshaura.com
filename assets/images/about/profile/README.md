# プロフィールカードの写真

このサイトについて（about/）のプロフィールカード左上に出る写真の置き場所です。
ページを開くたびに、ここの画像からランダムで1枚選ばれます。

## 写真を増やす（★拡張予定）

1. このフォルダに画像（PNG / JPG / WebP）を入れて push する
2. GitHub 上で自動処理「Avatar images」が動いて、軽量版（.webp）と一覧 `assets/images/about/list.json` が作られる
3. 数分後にサイトに反映される

- カードには正方形に切り抜いて表示します（上側を優先して表示）。顔が上の方にある画像がきれいに収まります。
- 1枚もないときは、トップページのキャラクター画像（assets/images/welcome/）から選びます。
- 写真を消すときは、このフォルダから画像（と同じ名前の .webp）を消して push するだけです。
