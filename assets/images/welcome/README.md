# トップページのキャラクター画像

トップページ（index.html）に出るキャラクターの画像置き場です。
ページを開くたびに、それぞれのフォルダからランダムに選ばれます。

| フォルダ | 出る場所 | 一度に出る数 |
|---|---|---|
| `left/` | キャラクター①：自己紹介のところで、左から傾いて現れる | 1人 |
| `right/` | キャラクター②：自己紹介のところで、右から傾いて現れる | 1人 |
| `footer/` | キャラクター③：いちばん下で、フッターの下からスライドインする | PC 4人・スマホ 2人 |

## 画像を追加・入れ替えする手順

1. 背景が透明な PNG を、使いたいフォルダに入れる（ファイル名は自由。英数字がおすすめ）
   - キャラクターの足元が画像の下端に来るようにする（足元はフッター・画面の下に少し隠れます）
   - 縦長〜正方形くらいの画像がきれいに収まります
2. GitHub に push する（GitHub Desktop でコミット → Push）
3. 数分待つと、自動で軽量版（WebP）と一覧（`list.json`）が作られて、サイトに反映されます
   - GitHub の Actions タブ →「Avatar images」が緑のチェックになれば完了

画像を消すときも、フォルダから消して push するだけです。

## 触らないファイル

- `list.json` … 画像の一覧（自動で作られる）
- `*.webp` … 軽量版（自動で作られる）

## 大きさ・傾き・人数を変えたいとき

- 大きさ・位置・傾き … `assets/welcome.css` の「キャラクター①（左）・②（右）」「セクション3」の変数
- フッターに並べる人数・キャラクター②の退場の向き … `assets/welcome.js` の `WLC_FOOTER_COUNT`・`WLC_EXIT_R_DIR`
