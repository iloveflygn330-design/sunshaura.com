# ページ移動アイコン（自動生成・手で触らない）

ページを移動するときの「ちょっとまってね...」「おまたせ！」の丸い画像です。
ページ移動のたびに、ここに登録されたセットからランダムに1セットが選ばれます（`assets/page-transition.js`）。

<!--
  ★拡張予定: アイコンのセットを増やす手順
    1. Discord のアイコン用チャンネル（ID: 1558856353685045248）に、画像を **2枚まとめて1回で** 投稿する
         1枚目 → 「ちょっとまってね...」
         2枚目 → 「おまたせ！」
       2枚ではない投稿には Bot がエラーを返信する（取り込まれない）
    2. 毎朝7時15分ごろ、自動で顔を中心に丸く切り抜いて登録される
       （すぐ登録したいときは GitHub の Actions タブ →「Gallery from Discord」→「Run workflow」）
    3. 元の投稿に ✅ が付き、切り抜いた結果のプレビューが返信される

  ★拡張予定: セットを外す
    元の投稿に ❌ を付ける → 次回の実行でここから消える

  ★拡張予定: 切り抜きの寄り具合・顔が見つからないときの位置を変える
    .github/scripts/discord-panel-icons.py の FACE_RATIO / FALLBACK_* を書き換える
    （すでに登録したセットは作り直されない。作り直したいセットは ❌ で外して投稿し直す）
-->

- `sets.json` … 登録されているセットの一覧
- `<投稿ID>_wait.webp` / `<投稿ID>_done.webp` … 丸く切り抜いた画像（256px、丸の外は透明）
- `discord-state.json` … Discord をどこまで読んだかの記録
- セットが1つもないとき、画像が読めないときは 🌸 を表示します
